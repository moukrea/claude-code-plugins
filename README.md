# claude-code-plugins

Security-focused Claude Code plugins.

## Plugins

### opaq

Secure credential manager and execution wrapper. Use secrets in commands without ever seeing them — for humans and AI agents alike.

**Install:**

```bash
opaq setup
```

Or manually:

```bash
claude plugin marketplace add moukrea/claude-code-plugins
claude plugin install opaq@claude-code-plugins --scope user
```

**Learn more:** [github.com/moukrea/opaq](https://github.com/moukrea/opaq)
